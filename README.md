Last updated: September 2026

Terms of Service
This is a personal, non-commercial SMS notification service. It sends automated calendar reminders and weekly schedule digests to a single end-user (the service operator) via text message.

Messages are triggered by upcoming events on the user's own Google Calendar. No marketing, promotional, or third-party content is sent.

Message frequency varies based on calendar activity, typically 10–30 messages per month. Message and data rates may apply.

The end-user may opt out at any time by replying STOP to any message. Reply HELP for support.

Privacy Policy
This service accesses Google Calendar data solely to determine upcoming event times and locations. Calendar data is read in real time and is not stored beyond the current script execution.

Phone numbers and message logs are used only for delivering reminders to the end-user. No personal data is sold, shared with, or disclosed to any third parties or affiliates for marketing or promotional purposes.

No mobile opt-in data or information collected as part of this messaging program will be shared with third parties.

Contact
For questions, reply HELP to any message or contact the service operator directly.
